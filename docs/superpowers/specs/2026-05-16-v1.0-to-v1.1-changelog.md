# v1.0 → v1.1 Changelog

**v1.0 launched:** 2026-05-15 (Apple same-day approval)
**v1.1 submitted:** 2026-05-16

This is the public record of everything fixed between those two dates. Maintained as a "lessons from reality" log — what shipping to real users surfaced that we couldn't see from inside.

## The principle this captures

**Reality is the only honest test environment.** Tonight's session shipped 5 PRs, fixed 4 separately-broken classes of menu-extraction failure, and surfaced 2 v1.2-blocking bugs (`spicy` content-filter false positive, missing coffee category) — none of which would have come up without v1.0 being live. The "feature complete" claim at submission time was wrong about half a dozen things. The fix loop is the real product.

Build. Test. **Ship.** Get reality's feedback. Fix. Repeat.

## What reality showed us (bugs that v1.0 couldn't have caught from the inside)

1. **DNS errors were being labelled `claude_error`** in the menu-refresh classifier. The catch-all default was wrong, but only visible once a real domain went dark in production.
2. **Anthropic's image-URL fetch path respects robots.txt.** Square's CDN denies crawlers in robots.txt. So every Square-hosted restaurant's image-based menu was silently failing — couldn't have seen this without trying a Square site in prod.
3. **Squarespace restaurants 302 their /menu URL directly to a PDF.** The pipeline downloaded the PDF bytes and treated them as HTML, extracting 60k of garbage. Required a real failure (19 Raw) to expose.
4. **Follow count was stale** for anyone who followed someone from a UserProfile page — React Query cache wasn't invalidating. Surfaced exactly because Dan tested it himself.
5. **Avatar showed in the followers list but not on the followed user's profile page** — same column, two different SELECT statements, one missed `avatar_url`. PR #194 had missed this code path. Caught by Dan eyeballing his own followers vs Zack's profile.
6. **`is_offensive()` blocks every dish name containing "spicy"** because `spic` is on the slur blocklist with substring matching. Caught while importing Aalia's "Extra Spicy Vegan Hash" — would have hit every "Spicy Tuna Roll" / "Spicy Margarita" insert forever.
7. **No coffee category** in the system. Users started asking to rate coffee within days of launch. Captured as v1.2 work.
8. **Restaurants uploading their menu as a generic screenshot** (Port Hunter) defeated candidate scoring because the filename has no menu keywords. Only visible by trying to refresh a real restaurant whose menu was an image.

Each one was invisible until reality made it visible.
